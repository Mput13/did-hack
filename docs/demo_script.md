# Сценарий показа: пульт робота

Показ идёт с одного Mac: слева окно Gazebo, справа браузер со страницей «Пульт».
Весь сценарий — около пяти минут: минута на запуск, четыре на езду.

Требования жюри, которые закрывает показ:

| № | Требование | Где видно |
|---|---|---|
| 1 | Работающий прототип робота в среде | окно Gazebo: TurtleBot3 Burger на арене |
| 2 | Генерация карты или статичная карта | карта на странице проявляется по лидару; бледная подложка — эталонная карта |
| 3 | Положение робота на карте | оранжевый кружок со стрелкой, след, лучи лидара |
| 4 | Задать точку назначения или маршрут | клик по карте ставит нумерованную точку |
| 5 | Движение по заданному маршруту | кнопка «Ехать»: синий пунктир — построенный путь |
| 6 | Полный сценарий | запуск → карта → задача → движение → результат, шаги ниже |

## За десять минут до показа

1. Остановить на Mac все тяжёлые расчёты (серии опытов, другие Gazebo). Если процессор занят,
   команды роботу запаздывают: страница покажет жёлтую строку «Компьютер перегружен», а робот
   поедет медленнее. На свободной машине этой строки нет.
2. В терминале, из папки проекта:

   ```bash
   pixi run demo --open
   ```

   Команда поднимает сервер интерфейса (если он ещё не запущен), стенд Gazebo с окном и пульт,
   печатает адрес страницы (`http://127.0.0.1:8765/#/pilot`) и с ключом `--open` открывает её в браузере.
   Другой сценарий: `pixi run demo --level hard --seed 1`. Остановить всё — `Ctrl+C` в этом терминале.
3. Расставить окна: Gazebo слева, браузер справа (страница рассчитана на ширину от 1280 точек).
4. Дождаться на странице статуса «Жду команду» — около 45 секунд от запуска. Стенд можно поднять заранее
   и перед выходом нажать «Сбросить»: карта и след сотрутся, судья начнёт прогон заново.

## Шаги показа

| Шаг | Что нажать | Что сказать | Что видит зритель | Требование |
|---|---|---|---|---|
| 0. Запуск | `pixi run demo --open` (или уже запущено) | «Одна команда поднимает мир, робота, судью и пульт» | окно Gazebo с ареной; на странице — статус «Робот оседает на колёса: ещё N с» | 1, 6 |
| 1. Карта из одной точки | ничего, показать на карту | «Робот ещё не тронулся, а лидар уже нарисовал треть арены: белое — увидел, серое — ещё нет» | белый «веер» вокруг робота, чёрные стены, «Карта построена: 36 %» | 2, 3 |
| 2. Маршрут | 5–6 кликов по карте по кругу арены (см. схему ниже) | «Ставлю точки — пульт сразу строит путь в обход столбов и пишет его длину» | нумерованные синие точки, пунктир пути, «путь 10,4 м» | 4 |
| 3. Объезд | «Ехать» | «Робот едет по маршруту, карта достраивается на глазах; поза — одометрия с поправкой по лидару» | робот движется в Gazebo и на карте, новые клетки вспыхивают оранжевым, растёт «Карта построена», в конце «100 %» и «Совпадение с эталоном 98 %» | 5, 2, 3 |
| 4. Цель | один клик в дальний угол, «Ехать» | «Теперь одна точка назначения: приехал с точностью до сантиметров» | зелёная строка «Приехал: до заданной точки 4 см» | 4, 5 |
| 5. Домой | «Домой» | «Одна кнопка — и робот возвращается на базу» | путь до базы, «Робот на базе: до её центра 5 см» | 5 |
| 6. Миссия | «Запустить миссию» (агент «С адаптацией») | «А теперь без оператора: робот сам ищет образцы по датчику, решает, куда ехать, и возвращается» | зелёные пятна — где агент ждёт образец; справа его план и журнал; счётчик «собрано 2 из 5» | 6 |
| 7. Итог | дождаться конца (около 100 с), включить «Показать скрытую правду» | «Собрал все пять, вернулся, счёт судьи 72. Вот что было скрыто: образцы и дорогие грунты» | итог миссии: собрано, на базе, счёт, время; на карте — образцы и грунты | 6 |

Точки для объезда (шаг 2) — по часовой стрелке вокруг центра, между столбами:
левее и выше базы (−1,6; 0,6) → верх (−0,55; 1,6) → центр-право (0,55; 0,55) → правый край (1,6; −0,55) →
низ (0,55; −1,6) → левее центра (−0,55; −0,55). Цель для шага 4 — правый верхний угол (1,5; 1,2).
Точность клика не важна: точку у самой стены пульт сам отодвинет, а клик в столб или за стену отклонит
красной строкой «Точка попала в стену или столб» — это тоже можно показать.

Сколько это занимает (замер в Gazebo, средний уровень, сценарий 3): готовность через 45 с после запуска,
объезд 10,4 м — 53 с, цель 3 м — 16 с, домой 4,4 м — 22 с, миссия — 96–100 с.

## Что на странице

- **Карта.** Серое — эталонная карта арены (подложка), белое и чёрное — то, что робот увидел лидаром сам.
  «Карта построена» — доля пола, уже увиденная лидаром; «Совпадение с эталоном» — доля увиденных клеток,
  где наша карта и эталонная согласны.
- **Откуда поза.** «Колёса + лидар»: одометрия колёс уходит, пульт поправляет её, прикладывая скан к карте;
  рядом — величина поправки.
- **Заряд и датчик образцов** — то, что публикует судья (`/did/battery`, `/did/sample_sensor`).
  Ручная езда тратит заряд; перед миссией пульт просит судью начать прогон заново, поэтому миссия
  стартует с полным зарядом и со всеми образцами.
- **Показать скрытую правду** — образцы, грунты и опасные зоны из состояния судьи. По умолчанию выключено:
  агент их не видит.

## Если что-то пошло не так

| Что случилось | Что делать |
|---|---|
| Статус «Жду стенд Gazebo» дольше минуты, окна Gazebo нет | `Ctrl+C`, ещё раз `pixi run demo`. Журналы: `runs/_logs/demo-stand.log`, `runs/_logs/demo-pilot.log` |
| Жёлтая строка «Компьютер перегружен» | закрыть лишние программы; робот в это время едет медленнее. Если не помогло — запасной вариант ниже |
| Робот упёрся или едет не туда | «Стоп», затем «Домой»; пульт сам отъезжает от преграды и строит путь заново |
| Миссия идёт плохо (столкновения, робот потерялся) | «Завершить миссию», «Домой», «Сбросить», запустить миссию ещё раз |
| Заряд кончился во время ручной езды | ничего: пульт сам попросит судью начать прогон заново |
| Gazebo завис или упал | запасной вариант ниже — тот же пульт, та же страница |
| Страница «не подключена к роботу» | проверить терминал с `pixi run demo`; страницу обновлять не нужно, она сама переподключится |

**Запасной вариант без Gazebo.** На странице «Пульт», внизу справа, блок «Где едет робот» →
«Перейти на быстрый симулятор» (или в терминале: `pixi run demo --fast`). Это тот же класс пульта, та же арена
и тот же судья, только вместо Gazebo — быстрый симулятор внутри сервера; одометрия в нём тоже уходит,
и лидар её так же поправляет. Сценарий показа тот же самый, шаги 1–7; время можно ускорить кнопками ×2, ×4, ×8
(на миссии удобно ×2). Вернуться к Gazebo — кнопка «Вернуться к Gazebo» там же.

**Совсем запасной вариант** — видеозаписи в папке `demo/`: `pilot_fastsim.mp4` — полный сценарий на странице
пульта (быстрый симулятор), `pilot_gazebo_tour.mp4` и `gazebo_tour.mp4` — объезд в Gazebo: страница пульта и окно
Gazebo. Ключевые кадры — в `demo/shots/`.

**Репетиция без человека.** При запущенном показе команда `pixi run python tools/demo_check.py` сама проходит
весь сценарий (объезд, цель, домой, миссия) и печатает, что получилось на каждом шаге. Удобно прогнать за
полчаса до выхода.

## Команды

```bash
pixi run demo                          # Gazebo с окном, средний уровень, сценарий 3
pixi run demo --level hard --seed 1    # другой сценарий
pixi run demo --fast                   # без Gazebo, быстрый симулятор
pixi run demo --no-gui                 # Gazebo без окна (проверка на слабой машине)
pixi run python tools/gz_record.py --out demo/gazebo.mp4 --view iso   # записать окно Gazebo
```
