# Демонстрация

Откройте http://127.0.0.1:8765/#/pilot после `pixi run demo` (Gazebo) либо
`pixi run demo --fast` (быстрый симулятор). Адрес пульта сохранён для совместимости.

1. Проверьте источник данных в заголовке. В быстром симуляторе можно применить
   статичный сценарий либо сценарий с изменениями среды, указав его номер.
   Контур и столбы в обоих случаях соответствуют эталонной арене; меняются
   образцы, грунты и события. Сценарий Gazebo меняется при перезапуске стенда.
2. Выберите задание: движение по точкам либо автономный сбор и возврат.
3. Для маршрута выберите инструмент и кликните по карте. Жёлтая зона —
   предпочтение обхода (стоимость планирования ×4), красная — запрет проезда
   с запасом для корпуса. Радиус настраивается. Зоны можно убрать вместе.
   Они не изменяют физику, расход судьи и скрытую правду среды. Для автономной
   миссии зоны оператора нужно убрать: агент изучает сам сценарий.
4. Запустите задание, наблюдайте положение робота, построенный и пройденный
   пути, заряд и расстояние. «Стоп» сохраняет маршрут. После завершения
   появляется результат; для автономной миссии можно открыть запись.
5. «Сравнить с LLM» открывает сохранённую пару внутри страницы. Два прогона
   имеют общую шкалу времени, каждый можно открыть отдельно. Условия пары
   проверяются сервером: сценарий, правила, backend и все записанные настройки
   агента, кроме названия и типа планировщика, должны совпадать.

Сравнение использует существующие записи `runs/llm_real/rule` и
`runs/llm_real/mai-qwen3.8-flash-next`, а не имитатор LLM. Новых запросов к
провайдеру при просмотре нет. Результат на одном сценарии не является выводом
о преимуществе модели на всех сценариях. Время симуляции и суммарное ожидание
ответов API показаны отдельно. Текущая живая миссия использует численный агент,
выбранный в списке «Агент» (по умолчанию `adaptive`; для показа на трудном уровне — «Исследователь, пережидает
сбой датчика», см. `docs/demo_script.md`); просмотр записей с LLM не подключает LLM к текущему роботу.

Репетиция показа без человека (при запущенном `pixi run demo --level hard --seed 2 --agent scientist_v2`):

```bash
pixi run python tools/demo_check.py --agent scientist_v2 --tour short --no-goal --expect hard 2 --min-samples 7 --clean
```

Она проходит объезд и миссию и отвечает «репетиция прошла» только если объезд пройден по всем точкам, миссия шла
на новом прогоне судьи, собраны все семь образцов без заездов в опасные зоны и ложных сборов, робот вернулся.
Имя агента в `--agent` и в адресе страницы (`?agent=…`) проверяется: неизвестное имя — ошибка запуска и
предупреждение на странице, а не молчаливая замена.

«Опыты», «Сценарии», «Знания» остаются в навигации. Конструктор задания
исследования доступен через «Новое исследование» в «Опытах» и адрес `#/study`.
